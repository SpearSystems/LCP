## Responsibilities

- Review and merge pull requests
- Triage issues and security reports
- Approve extension registry registrations (format check only)
- Manage spec versioning and deprecation cycles
- Update conformance test vectors

## Becoming a Maintainer

LCP currently has a single maintainer. As the community grows, additional
maintainers may be added by mutual agreement of the existing maintainers.
There is no formal process yet — this will be documented when the project
adopts a multi-maintainer governance model.
