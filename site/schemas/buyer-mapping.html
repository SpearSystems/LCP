LCP Buyer Delivery Mapping (LEP-0015, format 1.0)

https://lcp.dev/schemas/buyer-mapping.json · A platform document, not a message type. It turns an LCP post into one buyer API request and the buyer's response into an LEP-0012 outcome. Data, not code: no expressions, a closed transform set and a closed rule language. Every object is closed. The normative execution rules are in docs/BUYER-MAPPING.md; a platform also refuses at upsert what this schema cannot express (attribute paths that the declared vertical versions do not define, regulated paths for an unenrolled buyer, egress-rule failures).
