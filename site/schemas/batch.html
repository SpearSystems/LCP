LCP Batch Message

https://lcp.dev/schemas/batch.json · v1.2 (LEP-0001 W2-01): bounded batch submission. The batch is a loop over the single-item intake path — each item's payload is a lead payload validated by schemas/lead.json, authenticated, deduped, and persisted exactly as a single lead would be. The batch schema therefore fixes the per-item metadata (item_id, idempotency_key) and the item payload's container, never the lead's own field rules: an item whose lead payload is invalid is a per-item `rejected` receipt, not a whole-request schema failure. Created by Spear Systems (a Spear company). Open standard — Apache 2.0, free to implement.
