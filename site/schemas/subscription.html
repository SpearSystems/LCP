LCP Subscription Message

https://lcp.dev/schemas/subscription.json · v1.2 (LEP-0001 W3): event-subscription registration and its resource view. The payload is a strict object: an explicit event allowlist drawn from the receiver's advertised `capabilities().events`, an HTTPS callback URL, and a filter whose keys are a closed set of core enums and identifiers. Consumer, provenance, attributes, details, contact, and security paths are never filter keys. The registration response carries `subscription_id`, `active`, `created_at`, and the per-subscription `secret` exactly once. Created by Spear Systems (a Spear company). Open standard — Apache 2.0, free to implement.

Top-level properties

PropertyTypePII classRequiredDescription
activebooleaninternalSubscription state. A disabled subscription receives no new deliveries.
callback_urlstringinternalyesHTTPS callback destination (http only in an explicitly configured sandbox). Validated with the conformance runner's SSRF rule: no embedded credentials, a valid port, and only public resolved addresses.
created_atstringinternalRegistration time in whole-second UTC form.
event_typesarrayinternalyesExplicit event allowlist. Values are the receiver's advertised event names; no wildcard and no second vocabulary exist. An unadvertised value is refused, never silently ignored.
filterobjectinternalClosed filter over core enums and identifiers. Any other key, including consumer.email, provenance.*, and attributes.*, is refused with a named error.
replay_fromstringinternalOpaque cursor from GET /v1/lcp/events. A subscription created with it replays that event set deterministically; an expired cursor is an explicit error.
secretstringrestrictedPer-subscription HMAC secret. Returned exactly once on registration and never again; deliveries are signed with it over the LEP-0002 canonical input.
subscription_idstringinternalOpaque subscription identifier returned on registration. It is not a bearer credential: every read, disable, and delivery is authorized against the subscriber's tenant.
