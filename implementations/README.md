# LCP — Reference Implementations

## mcp-server (planned)

The official LCP MCP server — a thin adapter exposing LCP as agent
tools: `submit_lead`, `submit_call`, `query_lead_status`, `get_schema`,
`get_capabilities`, `list_offers`. Generic: works with any LCP-compliant
endpoint. SpearPointX is the first wired endpoint.

Status: **not started** — lands after the spec is finalized (v1.0).
